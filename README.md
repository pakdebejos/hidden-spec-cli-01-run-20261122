mend — one patch tool for every AI edit format. A single-file TypeScript CLI that applies patches written in the common AI edit formats (search/replace blocks, unified-style hunks and V4A-style chunks) exactly as their specs read, with literal corner handling for chunk starts, end-of-file chunks and bounded marker search.

## Run it

```sh
node --experimental-strip-types main.ts <patch-file>
```
